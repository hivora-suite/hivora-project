# Vision

## Pourquoi

Les équipes qui hébergent leurs propres outils doivent choisir entre des suites de gestion de projet lourdes et des outils trop limités. Hivora Project propose un outil volontairement simple, que l'on installe en quelques minutes et dont les données restent chez soi.

## Pour qui

| Profil | Besoin |
|---|---|
| Responsable de projet | Organiser le travail et savoir où il en est, sans configuration longue |
| Membre d'équipe | Voir ses tâches, les faire avancer, échanger dessus |
| Administrateur de l'instance | Installer, gérer les comptes, sauvegarder, mettre à jour sans effort |

## Promesse

- Une équipe devient opérationnelle le jour de l'installation.
- Une seule instance, un seul conteneur, des données locales.
- Une interface cohérente avec le reste de la suite Hivora.

## Non-objectifs

- Service hébergé ou multi-organisations.
- Accumuler les fonctionnalités d'une suite complète.
- Architecture distribuée.
- Personnalisation poussée : champs libres, automatisations, moteur de règles.

Une demande qui relève d'un non-objectif est refusée, ou fait l'objet d'une décision explicite dans `decisions.md`.
