# Changelog

## [Non publié]

- Valider ou dévalider une tâche : un statut, la carte ne bouge pas ; la poser dans Terminé la valide ; noté dans son journal.
- Planning : un élément sur plusieurs jours est une seule barre ; au-delà de 3 lignes, « +N » ouvre un menu des autres éléments ; les cartes prennent la couleur de leur première étiquette.
- Kanban : les déplacements et validations partent un par un, dans l'ordre (deux gestes rapides pouvaient s'inverser).
- Kanban : l'onglet Tableau devient Kanban ; « Mon kanban » réunit mes cartes de tous les projets, que je range parmi mes tâches perso dans mes propres colonnes, dans un seul ordre ; fond sombre sous les confirmations ouvertes depuis une carte.
- Planning : calendrier du mois de chaque projet, cartes de leur début à leur échéance, événements du projet avec heures ou sur la journée, vues jour, semaine, mois et année, glisser pour créer, un même événement sur plusieurs jours choisis avec Ctrl + clic ; « Mon planning » avec mes cartes de tous mes projets et mes événements privés.
- Projets : suppression définitive ; épinglage par compte dans le menu, depuis la page Projets ou le titre du projet ouvert.
- Étiquettes : 12 couleurs ; confirmations et saisies dans le style de l'application.
- Sécurité : limitation des essais étendue aux requêtes parallèles et aux vérifications depuis une session ; désactiver le TOTP ferme les autres sessions ; en-têtes contre l'affichage dans un cadre ; avertissement en mode `public` sans proxy de confiance ; l'historique ne garde plus le texte des commentaires.
- Historique des modifications de chaque carte.
- Commentaires sur les cartes.
- Cartes : dates, checklist, étiquettes, plusieurs membres ; animations fluides du Kanban.
- Navigation : onglets du projet dans la barre latérale ; accès aux projets choisi depuis les comptes.
- Tableau Kanban : glisser-déposer des tâches, déplacement au clavier, ordre des colonnes.
- Tâches et colonnes : création, assignation, colonnes par défaut.
- Projets : création, membres et rôles par projet, archivage.
- Comptes et connexion : mots de passe, sessions, double authentification, codes de secours, rôles.
